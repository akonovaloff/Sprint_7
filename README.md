# Sprint_7: Тестирование API Яндекс Самокат

## Описание проекта
Проект включает тестирование API учебного сервиса Яндекс Самокат. Проверяются основные ручки: создание курьера, авторизация, создание заказа и получение списка заказов.

## Тестируемые ручки

### [Создание курьера](tests/test_create_courier.py)
- [x] Проверка создания курьера.
- [x] Проверка невозможности создания дубликата курьера.
- [x] Проверка обязательных полей.
- [x] Проверка кодов ответа и тела ответа.

### [Логин курьера](tests/test_login_courier.py)
- [x] Проверка успешной авторизации курьера.
- [x] Проверка возврата `id` при успешной авторизации.
- [x] Проверка обязательных полей для авторизации.
- [x] Проверка ошибки если курьер не зарегистрирован.
- [x] Проверка ошибки входа для пустых обязательных полей.
- [x] Проверка ошибки входа с несовпадающим паролем.

### [Создание заказа](tests/test_orders.py)
- [x] Проверка создания заказа с указанием цвета (BLACK, GREY, оба цвета или без цвета).
- [x] Проверка возврата `track` в теле ответа.
- [x] Использование параметризации для тестирования различных вариантов.

### [Список заказов](tests/test_orders.py)
- [x] Проверка возврата списка заказов в теле ответа.

### [Удаление курьера](tests/test_delete_courier.py)
- [x] Неуспешный запрос возвращает соответствующую ошибку;
- [x] Успешный запрос возвращает `{"ok":true}`;
- [x] Если отправить запрос без id, вернётся ошибка;
- [x] Если отправить запрос с несуществующим id, вернётся ошибка.

## Запуск тестов
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   
2. Запуск тестов:
   ```bash
   pytest tests/ -n=4
   ```
   
3. Запуск тестов и генерация отчета Allure:
   ```bash
   pytest tests/ -n=4 --alluredir=allure-results
   allure serve allure-results
   ```
