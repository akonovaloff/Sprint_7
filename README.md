# Sprint_7
# Тестирование API Яндекс Самокат

## Описание проекта
Проект включает тестирование API учебного сервиса Яндекс Самокат. Проверяются основные ручки: создание курьера, авторизация, создание заказа и получение списка заказов.

## Тестируемые ручки

### [Создание курьера](tests/test_create_courier.py)
- [ ] Проверка создания курьера.
- [ ] Проверка невозможности создания дубликата курьера.
- [ ] Проверка обязательных полей.
- [ ] Проверка кодов ответа и тела ответа.
- [ ] Проверка ошибок при отсутствии обязательных полей или дублировании логина.

### [Логин курьера](tests/test_login_courier.py)
- [ ] Проверка авторизации курьера.
- [ ] Проверка обязательных полей для авторизации.
- [ ] Проверка ошибок при неверном логине/пароле или отсутствии полей.
- [ ] Проверка возврата `id` при успешной авторизации.

### Создание заказа
- [ ] Проверка создания заказа с указанием цвета (BLACK, GREY, оба цвета или без цвета).
- [ ] Проверка возврата `track` в теле ответа.
- [ ] Использование параметризации для тестирования различных вариантов.

### Список заказов
- [ ] Проверка возврата списка заказов в теле ответа.

## Отчёт Allure

## Запуск тестов
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   
2. Запуск тестов:
   ```bash
   pytest tests/ -n=4
   ```
   
3. Запуск тестов и генерация отчета Allure:
   ```bash
   pytest tests/ -n=4 --alluredir=allure-results
   allure serve allure-results
   ```
